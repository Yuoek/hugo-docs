
# C语言循环链表详解

## 1. 基本概念

### 什么是循环链表？
- 循环链表是链表的最后一个节点指向第一个节点，形成一个环状结构
- 与普通链表的区别：尾节点的next指针不为NULL，而是指向头节点

### 循环链表的类型
```c
// 单向循环链表
struct Node {
    int data;
    struct Node* next;
};

// 双向循环链表
struct DNode {
    int data;
    struct DNode* prev;
    struct DNode* next;
};
```

## 2. 基本操作实现

### 节点结构定义
```c
typedef struct Node {
    int data;
    struct Node* next;
} Node;
```

### 创建节点
```c
Node* createNode(int data) {
    Node* newNode = (Node*)malloc(sizeof(Node));
    newNode->data = data;
    newNode->next = newNode;  // 指向自己，形成循环
    return newNode;
}
```

### 插入操作对比表

| 操作类型 | 普通链表 | 循环链表 |
|---------|---------|----------|
| 头插法 | `newNode->next = head; head = newNode;` | `newNode->next = head->next; head->next = newNode;` |
| 尾插法 | 遍历到尾部再插入 | `newNode->next = head->next; head->next = newNode; head = newNode;` |
| 空表插入 | `head = newNode; newNode->next = NULL;` | `head = newNode; newNode->next = head;` |

### 具体实现代码

#### 在头部插入
```c
void insertAtHead(Node** head, int data) {
    Node* newNode = createNode(data);
    
    if (*head == NULL) {
        *head = newNode;
        return;
    }
    
    newNode->next = (*head)->next;
    (*head)->next = newNode;
}
```

#### 在尾部插入
```c
void insertAtTail(Node** head, int data) {
    Node* newNode = createNode(data);
    
    if (*head == NULL) {
        *head = newNode;
        return;
    }
    
    newNode->next = (*head)->next;
    (*head)->next = newNode;
    *head = newNode;  // 更新尾指针
}
```

#### 删除节点
```c
void deleteNode(Node** head, int key) {
    if (*head == NULL) return;
    
    Node *current = (*head)->next, *prev = *head;
    
    // 遍历查找要删除的节点
    do {
        if (current->data == key) {
            prev->next = current->next;
            
            // 如果删除的是头节点
            if (current == *head) {
                if (current->next == current) {  // 只有一个节点
                    *head = NULL;
                } else {
                    *head = prev;
                }
            }
            
            free(current);
            return;
        }
        prev = current;
        current = current->next;
    } while (current != (*head)->next);
}
```

## 3. 遍历操作

### 遍历循环链表
```c
void displayList(Node* head) {
    if (head == NULL) {
        printf("链表为空\n");
        return;
    }
    
    Node* temp = head->next;
    
    do {
        printf("%d -> ", temp->data);
        temp = temp->next;
    } while (temp != head->next);
    
    printf("(回到起点)\n");
}
```

## 4. 约瑟夫环问题（经典应用）

```c
// 约瑟夫环：n个人围成一圈，从第k个人开始报数，数到m的人出列
void josephus(int n, int k, int m) {
    // 创建循环链表
    Node* head = createNode(1);
    Node* prev = head;
    
    for (int i = 2; i <= n; i++) {
        Node* newNode = createNode(i);
        prev->next = newNode;
        prev = newNode;
    }
    prev->next = head;  // 形成环
    
    // 移动到第k个人
    Node* current = head;
    for (int i = 1; i < k; i++) {
        current = current->next;
    }
    
    printf("出列顺序: ");
    while (current->next != current) {
        // 数到第m-1个人
        for (int i = 1; i < m - 1; i++) {
            current = current->next;
        }
        
        // 删除第m个人
        Node* toDelete = current->next;
        printf("%d ", toDelete->data);
        current->next = toDelete->next;
        
        if (toDelete == head) {
            head = current->next;
        }
        
        free(toDelete);
        current = current->next;
    }
    
    printf("\n最后剩下: %d\n", current->data);
    free(current);
}
```

## 5. 循环链表的优缺点

### 优点
- 可以从任意节点开始遍历整个链表
- 某些操作（如轮询调度）更加高效
- 实现环形缓冲区等数据结构更方便

### 缺点
- 实现相对复杂，需要特别注意循环条件
- 容易造成无限循环
- 内存管理需要更加小心

## 6. 注意事项

1. **循环条件**：使用 `do-while` 循环或记录起始点
2. **空链表判断**：`head == NULL`
3. **单节点情况**：`head->next == head`
4. **内存释放**：需要特殊处理以避免内存泄漏

```c
// 正确的内存释放
void freeList(Node** head) {
    if (*head == NULL) return;
    
    Node* current = (*head)->next;
    Node* nextNode;
    
    while (current != *head) {
        nextNode = current->next;
        free(current);
        current = nextNode;
    }
    
    free(*head);
    *head = NULL;
}
```

循环链表是数据结构中的重要概念，熟练掌握其操作对于理解更复杂的数据结构很有帮助。
