
# 顺序栈（Sequential Stack）学习笔记

## 基本概念
**顺序栈**：使用**顺序存储结构**（数组）实现的栈，具有"后进先出"(LIFO)的特性。

## 数据结构定义

### C语言实现
```c
#define MAXSIZE 100  // 栈的最大容量

typedef struct {
    ElemType data[MAXSIZE];  // 存储栈元素的数组
    int top;                 // 栈顶指针
} SqStack;
```

## 核心操作详解

### 1. 初始化栈
```c
void InitStack(SqStack *S) {
    S->top = -1;  // 栈空标志：top = -1
}
```

### 2. 判断栈空
```c
int StackEmpty(SqStack S) {
    return (S.top == -1);  // top为-1表示栈空
}
```

### 3. 判断栈满
```c
int StackFull(SqStack S) {
    return (S.top == MAXSIZE - 1);  // top指向最后一个位置表示栈满
}
```

### 4. 入栈操作
```c
int Push(SqStack *S, ElemType e) {
    if (StackFull(*S)) {
        return 0;  // 栈满，入栈失败
    }
    S->top++;           // 栈顶指针上移
    S->data[S->top] = e; // 元素入栈
    return 1;           // 入栈成功
}
```

### 5. 出栈操作
```c
int Pop(SqStack *S, ElemType *e) {
    if (StackEmpty(*S)) {
        return 0;  // 栈空，出栈失败
    }
    *e = S->data[S->top];  // 保存栈顶元素
    S->top--;              // 栈顶指针下移
    return 1;              // 出栈成功
}
```

### 6. 获取栈顶元素
```c
int GetTop(SqStack S, ElemType *e) {
    if (StackEmpty(S)) {
        return 0;  // 栈空，获取失败
    }
    *e = S.data[S.top];  // 获取栈顶元素但不删除
    return 1;
}
```

## 操作流程示意图

### 入栈过程
```
初始状态：top = -1
Push(A): top=0, data[0]=A
Push(B): top=1, data[1]=B
Push(C): top=2, data[2]=C
```

### 出栈过程
```
当前：top=2, data[2]=C
Pop(): 返回C, top=1
Pop(): 返回B, top=0
Pop(): 返回A, top=-1
```

## 时间复杂度分析

| 操作 | 时间复杂度 | 说明 |
|------|------------|------|
| 初始化 | O(1) | 只需设置top指针 |
| 判断空/满 | O(1) | 比较top指针值 |
| 入栈 | O(1) | 直接数组赋值 |
| 出栈 | O(1) | 直接修改top指针 |
| 获取栈顶 | O(1) | 直接访问数组元素 |

## 优缺点对比

### 优点
- ✅ **访问速度快**：数组随机访问，时间复杂度O(1)
- ✅ **内存连续**：缓存友好，访问效率高
- ✅ **实现简单**：代码逻辑清晰易懂

### 缺点
- ❌ **容量固定**：需要预先确定栈的最大容量
- ❌ **空间浪费**：可能分配过多未使用的空间
- ❌ **扩容困难**：栈满时需要重新分配更大数组

## 实际应用场景

1. **函数调用栈**：程序执行时的函数调用关系
2. **表达式求值**：中缀表达式转后缀表达式
3. **括号匹配**：检查代码中的括号是否成对出现
4. **浏览器历史记录**：前进后退功能
5. **撤销操作**：编辑器的撤销功能

## 重要注意事项

1. **栈空判断**：出栈前必须检查栈是否为空
2. **栈满判断**：入栈前必须检查栈是否已满
3. **指针边界**：top指针不能越界（-1 ≤ top ≤ MAXSIZE-1）
4. **内存管理**：静态分配，无需手动释放内存

## 扩展思考

**顺序栈 vs 链式栈**
- 顺序栈：空间固定，访问速度快
- 链式栈：动态扩容，但需要额外指针空间

掌握顺序栈是理解栈这种数据结构的基础，为后续学习更复杂的数据结构打下坚实基础。
