
# C语言双链表详解

## 双链表基本概念

### 定义与特点
双链表（双向链表）是一种链式存储结构，每个节点包含：
- 数据域：存储数据元素
- 两个指针域：分别指向前驱节点和后继节点

```c
typedef struct Node {
    int data;           // 数据域
    struct Node* prev;  // 前驱指针
    struct Node* next;  // 后继指针
} Node;
```

### 与单链表的对比

| 特性 | 单链表 | 双链表 |
|------|--------|--------|
| 指针数量 | 1个(next) | 2个(prev, next) |
| 遍历方向 | 只能单向 | 可双向遍历 |
| 插入/删除效率 | O(n) | O(1)（已知位置） |
| 空间占用 | 较小 | 较大 |
| 实现复杂度 | 简单 | 相对复杂 |

## 双链表基本操作

### 1. 节点创建
```c
Node* createNode(int data) {
    Node* newNode = (Node*)malloc(sizeof(Node));
    newNode->data = data;
    newNode->prev = NULL;
    newNode->next = NULL;
    return newNode;
}
```

### 2. 链表初始化
```c
typedef struct {
    Node* head;  // 头指针
    Node* tail;  // 尾指针
    int size;    // 链表长度
} DoublyLinkedList;

void initList(DoublyLinkedList* list) {
    list->head = NULL;
    list->tail = NULL;
    list->size = 0;
}
```

## 核心操作实现

### 插入操作对比表

| 操作类型 | 单链表实现 | 双链表实现 | 时间复杂度 |
|----------|------------|------------|------------|
| 头部插入 | 需要遍历到头部 | 直接操作head | O(1) |
| 尾部插入 | 需要遍历到尾部 | 直接操作tail | O(1) |
| 中间插入 | 需要找到前驱节点 | 可直接操作前后节点 | O(1) |

### 具体实现代码

#### 头部插入
```c
void insertAtHead(DoublyLinkedList* list, int data) {
    Node* newNode = createNode(data);
    
    if (list->head == NULL) {
        // 空链表
        list->head = list->tail = newNode;
    } else {
        newNode->next = list->head;
        list->head->prev = newNode;
        list->head = newNode;
    }
    list->size++;
}
```

#### 尾部插入
```c
void insertAtTail(DoublyLinkedList* list, int data) {
    Node* newNode = createNode(data);
    
    if (list->tail == NULL) {
        list->head = list->tail = newNode;
    } else {
        newNode->prev = list->tail;
        list->tail->next = newNode;
        list->tail = newNode;
    }
    list->size++;
}
```

#### 指定位置插入
```c
void insertAtPosition(DoublyLinkedList* list, int position, int data) {
    if (position < 0 || position > list->size) return;
    
    if (position == 0) {
        insertAtHead(list, data);
    } else if (position == list->size) {
        insertAtTail(list, data);
    } else {
        Node* newNode = createNode(data);
        Node* current = list->head;
        
        // 移动到指定位置的前一个节点
        for (int i = 0; i < position - 1; i++) {
            current = current->next;
        }
        
        newNode->next = current->next;
        newNode->prev = current;
        current->next->prev = newNode;
        current->next = newNode;
        
        list->size++;
    }
}
```

### 删除操作

#### 头部删除
```c
void deleteAtHead(DoublyLinkedList* list) {
    if (list->head == NULL) return;
    
    Node* temp = list->head;
    list->head = list->head->next;
    
    if (list->head != NULL) {
        list->head->prev = NULL;
    } else {
        list->tail = NULL; // 链表为空
    }
    
    free(temp);
    list->size--;
}
```

#### 尾部删除
```c
void deleteAtTail(DoublyLinkedList* list) {
    if (list->tail == NULL) return;
    
    Node* temp = list->tail;
    list->tail = list->tail->prev;
    
    if (list->tail != NULL) {
        list->tail->next = NULL;
    } else {
        list->head = NULL; // 链表为空
    }
    
    free(temp);
    list->size--;
}
```

## 遍历操作

### 正向遍历
```c
void traverseForward(DoublyLinkedList* list) {
    Node* current = list->head;
    while (current != NULL) {
        printf("%d ", current->data);
        current = current->next;
    }
    printf("\n");
}
```

### 反向遍历
```c
void traverseBackward(DoublyLinkedList* list) {
    Node* current = list->tail;
    while (current != NULL) {
        printf("%d ", current->data);
        current = current->prev;
    }
    printf("\n");
}
```

## 完整示例代码

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct Node {
    int data;
    struct Node* prev;
    struct Node* next;
} Node;

typedef struct {
    Node* head;
    Node* tail;
    int size;
} DoublyLinkedList;

// 初始化链表
void initList(DoublyLinkedList* list) {
    list->head = NULL;
    list->tail = NULL;
    list->size = 0;
}

// 创建新节点
Node* createNode(int data) {
    Node* newNode = (Node*)malloc(sizeof(Node));
    newNode->data = data;
    newNode->prev = NULL;
    newNode->next = NULL;
    return newNode;
}

// 在头部插入
void insertAtHead(DoublyLinkedList* list, int data) {
    Node* newNode = createNode(data);
    
    if (list->head == NULL) {
        list->head = list->tail = newNode;
    } else {
        newNode->next = list->head;
        list->head->prev = newNode;
        list->head = newNode;
    }
    list->size++;
}

// 在尾部插入
void insertAtTail(DoublyLinkedList* list, int data) {
    Node* newNode = createNode(data);
    
    if (list->tail == NULL) {
        list->head = list->tail = newNode;
    } else {
        newNode->prev = list->tail;
        list->tail->next = newNode;
        list->tail = newNode;
    }
    list->size++;
}

// 正向遍历
void traverseForward(DoublyLinkedList* list) {
    Node* current = list->head;
    printf("正向遍历: ");
    while (current != NULL) {
        printf("%d ", current->data);
        current = current->next;
    }
    printf("\n");
}

// 反向遍历
void traverseBackward(DoublyLinkedList* list) {
    Node* current = list->tail;
    printf("反向遍历: ");
    while (current != NULL) {
        printf("%d ", current->data);
        current = current->prev;
    }
    printf("\n");
}

int main() {
    DoublyLinkedList list;
    initList(&list);
    
    insertAtHead(&list, 10);
    insertAtTail(&list, 20);
    insertAtHead(&list, 5);
    insertAtTail(&list, 30);
    
    traverseForward(&list);  // 输出: 5 10 20 30
    traverseBackward(&list); // 输出: 30 20 10 5
    
    return 0;
}
```

## 应用场景总结

1. **需要双向遍历的场景**：如浏览器历史记录、文本编辑器撤销操作
2. **频繁在两端操作的场景**：如队列、双端队列的实现
3. **需要快速访问前后节点的场景**：如音乐播放器的播放列表

## 注意事项

1. **内存管理**：记得释放所有节点内存
2. **边界处理**：特别注意头尾节点的处理
3. **指针更新**：插入删除时要正确更新前后指针
4. **空链表判断**：操作前检查链表是否为空
