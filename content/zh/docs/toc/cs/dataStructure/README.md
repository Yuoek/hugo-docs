# 数据结构与算法 (C语言) 学习路线

## 第一阶段：基础准备
### C语言核心语法
- 数据类型、变量、运算符
- 控制结构（条件、循环）
- 函数与递归
- 指针与内存管理
- 结构体与联合体
- 文件操作

## 第二阶段：基础数据结构
### 线性结构
- 数组与字符串
- c语言 链表 单链表
  c语言 双链表
  c语言 循环链表
- c语言 栈 顺序栈
  c语言 链栈
- 队列（顺序队列、链队列、循环队列）

### 基础算法
- 排序算法（冒泡、选择、插入）
- 查找算法（顺序查找、二分查找）
- 递归应用

## 第三阶段：进阶数据结构
### 树结构
- 二叉树（遍历、性质）
- 二叉搜索树
- 平衡二叉树（AVL树）
- 堆与优先队列
- 哈夫曼树

### 图结构
- 图的表示（邻接矩阵、邻接表）
- 图的遍历（DFS、BFS）
- 最短路径算法
- 最小生成树

## 第四阶段：高级算法
### 算法设计技巧
- 分治算法
- 贪心算法
- 动态规划
- 回溯算法

### 高级应用
- 哈希表与散列
- 字符串匹配算法
- 排序算法进阶（快速排序、归并排序、堆排序）

## 第五阶段：综合实践
### 项目实战
- 实现完整的数据结构库
- 算法问题求解
- 性能分析与优化

### 推荐练习平台
- LeetCode
- 牛客网
- 浙江大学PAT考试

## 学习建议
1. 理论与实践结合，每个知识点都要动手实现
2. 注重时间复杂度与空间复杂度分析
3. 多做算法题，培养解题思维
4. 阅读经典教材和开源代码

## 推荐资源
**书籍：**
- 《数据结构（C语言版）》- 严蔚敏
- 《算法导论》
- 《C程序设计语言》

**在线资源：**
- 中国大学MOOC相关课程
- GeeksforGeeks
- Stack Overflow

按照这个路线循序渐进学习，配合大量编程练习，你将能够掌握C语言下的数据结构与算法核心知识。
