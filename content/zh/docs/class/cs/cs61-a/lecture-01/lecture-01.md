## 笔记

```python 

class Solution:
    def findNthDigit(self, n: int) -> int:
        k, cnt = 1, 9
        while k * cnt < n:
            n -= k * cnt
            k += 1
            cnt *= 10
        num = 10 ** (k - 1) + (n - 1) // k
        idx = (n - 1) % k
        return int(str(num)[idx])

```


这个代码实现了一个解决“寻找第 n 个数字”的问题的函数。下面是对代码的解析：

### 问题描述
给定一个正整数 `n`，要求找到数字序列中第 `n` 个数字。数字序列是由所有的整数按顺序排列组成的，比如：`123456789101112...`。

### 代码解析
1. **初始化变量**：
   ```python
   k, cnt = 1, 9
   ```
   - `k` 表示当前数字的位数（1位数、2位数、3位数等）。
   - `cnt` 表示当前位数的数字总数（1位数有9个，2位数有90个，3位数有900个，依此类推）。

2. **确定目标数字的位数**：
   ```python
   while k * cnt < n:
       n -= k * cnt
       k += 1
       cnt *= 10
   ```
   - 循环通过比较 `k * cnt` 和 `n` 来确定目标数字所在的位数。
   - 如果当前位数的所有数字的总位数小于 `n`，说明目标数字不在这一组，需要将 `n` 减去这些数字的总位数，然后进入下一组位数。
   - 每次循环后，`k` 增加 1（进入下一位数），`cnt` 乘以 10（下一位数的数字总数）。

3. **确定目标数字**：
   ```python
   num = 10 ** (k - 1) + (n - 1) // k
   ```
   - `10 ** (k - 1)` 是当前位数的第一个数字，比如对于 2 位数，起始数字是 `10`。
   - `(n - 1) // k` 是目标数字在当前位数组中的索引位置。

4. **确定目标数字中的具体位置**：
   ```python
   idx = (n - 1) % k
   ```
   - `(n - 1) % k` 是目标数字的具体位置（索引）在该数字中的第几位。

5. **返回结果**：
   ```python
   return int(str(num)[idx])
   ```
   - 将目标数字转为字符串，提取目标位置的字符并转换为整数返回。

### 示例
假设 `n = 15`：
- 初始：`k = 1, cnt = 9`
- 第一次循环：`1 * 9 < 15`，`n = 15 - 9 = 6`，`k = 2, cnt = 90`
- 退出循环：目标数字在 2 位数中。
- 计算目标数字：`num = 10 + (6 - 1) // 2 = 12`
- 计算目标位置：`idx = (6 - 1) % 2 = 1`
- 返回结果：目标数字是 `12` 的第 1 位，即 `2`。

最终返回结果为 `2`。

### 总结
该算法通过逐步缩小范围，确定目标数字所在的位数和具体位置，效率较高，适合处理较大的 `n` 值。
