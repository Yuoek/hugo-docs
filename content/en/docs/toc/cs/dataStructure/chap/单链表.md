
# C语言单链表详解

## 1. 单链表基本概念

### 定义
单链表是由**节点**组成的线性数据结构，每个节点包含：
- **数据域**：存储数据元素
- **指针域**：指向下一个节点的地址

```c
struct Node {
    int data;           // 数据域
    struct Node* next;  // 指针域
};
```

### 与数组的对比
| 特性 | 数组 | 单链表 |
|------|------|--------|
| 内存分配 | 连续 | 非连续 |
| 大小 | 固定 | 动态 |
| 插入/删除 | O(n) | O(1) |
| 随机访问 | O(1) | O(n) |

## 2. 单链表基本操作

### 节点定义
```c
typedef struct Node {
    int data;
    struct Node* next;
} Node;
```

### 创建新节点
```c
Node* createNode(int data) {
    Node* newNode = (Node*)malloc(sizeof(Node));
    newNode->data = data;
    newNode->next = NULL;
    return newNode;
}
```

### 插入操作

#### 头插法
```c
void insertAtHead(Node** head, int data) {
    Node* newNode = createNode(data);
    newNode->next = *head;
    *head = newNode;
}
```

#### 尾插法
```c
void insertAtTail(Node** head, int data) {
    Node* newNode = createNode(data);
    
    if (*head == NULL) {
        *head = newNode;
        return;
    }
    
    Node* temp = *head;
    while (temp->next != NULL) {
        temp = temp->next;
    }
    temp->next = newNode;
}
```

#### 在指定位置插入
```c
void insertAtPosition(Node** head, int data, int position) {
    if (position < 0) return;
    
    if (position == 0) {
        insertAtHead(head, data);
        return;
    }
    
    Node* newNode = createNode(data);
    Node* temp = *head;
    
    for (int i = 0; i < position - 1 && temp != NULL; i++) {
        temp = temp->next;
    }
    
    if (temp == NULL) return;
    
    newNode->next = temp->next;
    temp->next = newNode;
}
```

### 删除操作

#### 删除头节点
```c
void deleteAtHead(Node** head) {
    if (*head == NULL) return;
    
    Node* temp = *head;
    *head = (*head)->next;
    free(temp);
}
```

#### 删除尾节点
```c
void deleteAtTail(Node** head) {
    if (*head == NULL) return;
    
    if ((*head)->next == NULL) {
        free(*head);
        *head = NULL;
        return;
    }
    
    Node* temp = *head;
    while (temp->next->next != NULL) {
        temp = temp->next;
    }
    
    free(temp->next);
    temp->next = NULL;
}
```

#### 删除指定值
```c
void deleteByValue(Node** head, int value) {
    if (*head == NULL) return;
    
    // 如果要删除的是头节点
    if ((*head)->data == value) {
        deleteAtHead(head);
        return;
    }
    
    Node* temp = *head;
    while (temp->next != NULL && temp->next->data != value) {
        temp = temp->next;
    }
    
    if (temp->next != NULL) {
        Node* toDelete = temp->next;
        temp->next = temp->next->next;
        free(toDelete);
    }
}
```

### 查找操作
```c
Node* search(Node* head, int value) {
    Node* temp = head;
    while (temp != NULL) {
        if (temp->data == value) {
            return temp;
        }
        temp = temp->next;
    }
    return NULL;
}
```

### 遍历链表
```c
void printList(Node* head) {
    Node* temp = head;
    while (temp != NULL) {
        printf("%d -> ", temp->data);
        temp = temp->next;
    }
    printf("NULL\n");
}
```

### 获取链表长度
```c
int getLength(Node* head) {
    int length = 0;
    Node* temp = head;
    while (temp != NULL) {
        length++;
        temp = temp->next;
    }
    return length;
}
```

## 3. 完整示例程序

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct Node {
    int data;
    struct Node* next;
} Node;

// 所有上述函数实现...

int main() {
    Node* head = NULL;
    
    // 插入操作
    insertAtTail(&head, 10);
    insertAtTail(&head, 20);
    insertAtHead(&head, 5);
    insertAtPosition(&head, 15, 2);
    
    printf("链表内容: ");
    printList(head);  // 输出: 5 -> 10 -> 15 -> 20 -> NULL
    
    // 删除操作
    deleteByValue(&head, 15);
    printf("删除15后: ");
    printList(head);  // 输出: 5 -> 10 -> 20 -> NULL
    
    // 查找操作
    Node* found = search(head, 10);
    if (found != NULL) {
        printf("找到节点: %d\n", found->data);
    }
    
    printf("链表长度: %d\n", getLength(head));
    
    return 0;
}
```

## 4. 常见应用场景

1. **动态内存管理**：不需要预先知道数据量大小
2. **实现栈和队列**：链表是这些数据结构的基础
3. **多项式运算**：每个节点存储系数和指数
4. **内存管理**：操作系统中的空闲内存块管理
5. **图算法**：邻接表表示图

## 5. 注意事项

1. **内存泄漏**：记得释放所有节点
2. **空指针检查**：操作前检查指针是否为NULL
3. **边界条件**：处理空链表、单节点链表等情况
4. **指针操作**：注意指针的指向关系

```c
// 释放整个链表
void freeList(Node** head) {
    Node* current = *head;
    Node* next;
    
    while (current != NULL) {
        next = current->next;
        free(current);
        current = next;
    }
    
    *head = NULL;
}
```
