
好的，我们来系统地整理一下C语言中**链栈**的相关知识点。

链栈是栈的链式存储结构，其本质是一个**操作受限的单链表**，只允许在**表头**进行插入（入栈）和删除（出栈）操作。

---

### 1. 核心概念与特点

| 特性 | 描述 |
| :--- | :--- |
| **定义** | 采用链式存储结构实现的栈。 |
| **栈顶** | **链表的头结点**。所有操作都在头结点后进行，时间复杂度为O(1)。 |
| **栈底** | 链表的最后一个结点。 |
| **优点** | **动态扩容**，无需预先指定大小，不会出现栈满的情况（除非内存耗尽）。 |
| **缺点** | 每个结点都需要额外的指针域，空间开销比顺序栈稍大。 |
| **关键点** | 通常**不设头结点**，直接让栈顶指针`top`指向第一个元素结点。 |

---

### 2. 结点结构与类型定义

链栈的结点结构与单链表结点完全相同。

```c
// 链栈的结点定义
typedef struct StackNode {
    int data; // 数据域，这里以int为例，可以是任意类型
    struct StackNode *next; // 指针域，指向下一个结点
} StackNode;

// 链栈本身的管理结构（通常就是一个指针）
typedef struct {
    StackNode *top; // 栈顶指针
    // 可以添加一个count字段记录栈的长度，方便查询
    int count;
} LinkStack;
```
*更简单的写法（常见于教学）：直接用一个`StackNode*`类型的指针`top`来代表整个栈。*

---

### 3. 基本操作与代码实现（基于`LinkStack`结构）

#### a. 初始化栈

创建一个空栈，栈顶指针指向`NULL`。

```c
// 初始化链栈
void InitStack(LinkStack *S) {
    S->top = NULL;
    S->count = 0;
}
```

#### b. 判断栈是否为空

检查栈顶指针是否为`NULL`。

```c
// 判断栈是否为空
int IsEmpty(LinkStack *S) {
    // 如果栈顶指针为NULL，则栈为空
    return S->top == NULL;
    // 或者 return S->count == 0;
}
```

#### c. 入栈操作 (Push)

1.  为新元素分配结点空间。
2.  将新结点的`data`域赋值为入栈元素。
3.  将新结点的`next`指针指向当前的栈顶结点。
4.  修改栈顶指针`top`，使其指向新结点。
5.  栈长度+1。

```c
// 入栈
int Push(LinkStack *S, int value) {
    // 1. 创建新结点
    StackNode *newNode = (StackNode*)malloc(sizeof(StackNode));
    if (newNode == NULL) {
        printf("内存分配失败，入栈失败！\n");
        return 0; // 失败
    }

    // 2. 给新结点赋值
    newNode->data = value;
    
    // 3. 将新结点插入到栈顶
    newNode->next = S->top; // 新结点指向原栈顶
    S->top = newNode;       // 栈顶指针指向新结点
    
    // 4. 栈长度+1
    S->count++;
    return 1; // 成功
}
```

**入栈过程图示：**
```
初始： top -> [A| ] -> [B| ] -> ... -> NULL

Push(C)后：
1. 创建新结点 [C| ]
2. newNode->next = top;  // [C| ] -> [A| ]...
3. top = newNode;        // top -> [C| ] -> [A| ]...
```

#### d. 出栈操作 (Pop)

1.  检查栈是否为空。
2.  用一个指针`p`临时指向待删除的栈顶结点。
3.  获取栈顶结点的数据（可选，用于返回）。
4.  修改栈顶指针`top`，使其指向原栈顶的下一个结点。
5.  释放`p`所指结点的内存。
6.  栈长度-1。

```c
// 出栈
int Pop(LinkStack *S, int *value) {
    // 1. 检查栈空
    if (IsEmpty(S)) {
        printf("栈为空，无法出栈！\n");
        return 0; // 失败
    }

    // 2. 临时指针p指向栈顶结点
    StackNode *p = S->top;
    
    // 3. 获取栈顶元素的值（通过指针参数返回）
    *value = p->data;
    
    // 4. 更新栈顶指针
    S->top = p->next;
    
    // 5. 释放原栈顶结点的内存
    free(p);
    
    // 6. 栈长度-1
    S->count--;
    return 1; // 成功
}
```

#### e. 获取栈顶元素 (GetTop)

与出栈类似，但不删除结点。

```c
// 获取栈顶元素（不删除）
int GetTop(LinkStack *S, int *value) {
    if (IsEmpty(S)) {
        printf("栈为空！\n");
        return 0;
    }
    *value = S->top->data; // 直接读取栈顶结点的数据
    return 1;
}
```

#### f. 销毁栈

由于链栈是动态分配内存的，使用完毕后需要手动释放所有结点的内存，防止内存泄漏。

```c
// 销毁栈
void DestroyStack(LinkStack *S) {
    StackNode *p, *temp;
    p = S->top;
    while (p != NULL) {
        temp = p;       // temp指向当前要释放的结点
        p = p->next;    // p移向下一个结点
        free(temp);     // 释放当前结点
    }
    S->top = NULL; // 最后将栈顶指针置空
    S->count = 0;
}
```

---

### 4. 链栈 vs. 顺序栈

| 对比项 | 顺序栈 | 链栈 |
| :--- | :--- | :--- |
| **存储结构** | 数组 | 链表 |
| **空间** | 固定大小，可能溢出 | 动态分配，理论上无限（除非内存满） |
| **性能** | 所有操作都是O(1)，缓存友好 | 所有操作都是O(1)，但需要动态申请/释放内存 |
| **适用场景** | 栈的大小可预估、变化不大 | 栈的大小不可预估、变化剧烈 |

---

### 总结

链栈的核心要点可以概括为：
*   **结构**：一个单链表，`top`指针作为头指针。
*   **操作**：**所有操作都在链表头部进行**，这是实现O(1)时间复杂度的关键。
*   **内存**：需要手动管理结点的`malloc`和`free`。
